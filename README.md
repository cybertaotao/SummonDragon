# 召唤神龙 Web MVP

一款移动端优先、打开网页即可游玩的休闲合成进化小游戏。

## 本地运行

环境要求：Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

启动后终端会同时显示本机地址和局域网地址。手机与电脑连接同一个局域网后，可通过 `http://本机IP:3000` 访问。

## 构建

```bash
npm run build
npm run start
```

## 检查

```bash
npx tsc --noEmit
npm run lint
```

## 项目结构

```text
app/                     页面、弹窗与移动端界面
game/                    Phaser 游戏逻辑与难度配置
public/assets/           本地游戏美术资源
doc/MVP方案.md           已确认的产品方案
doc/开发与配置说明.md     开发、调参与部署说明
```

## 当前范围

- 简单、普通、困难三档难度
- 十级进化路线
- 玩家完整跟随链
- 野生生物随机游动和互相吞噬
- 自动三合一与连续进位
- 受击切断、胜利和失败判定
- 首次教程、暂停与横屏提示
- 首页背景音乐、吞噬/被吞噬音效、胜利/失败音效及统一声音开关

详细规则请阅读 [MVP 方案](./doc/MVP方案.md)。
