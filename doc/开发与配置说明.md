# 开发与配置说明

## 1. 技术结构

- 页面框架：React + TypeScript
- 游戏引擎：Phaser 4
- 构建工具：Vite / Vinext
- 本地状态：浏览器 `localStorage`
- 美术资源：全部保存在 `public`，运行时无外部图片依赖

页面弹窗和难度选择位于 `app/game-client.tsx`，游戏循环位于 `game/summon-dragon-scene.ts`。

## 2. 本地启动

安装 Node.js 22.13 或更高版本，然后执行：

```bash
npm install
npm run dev
```

浏览器访问终端打印的 Local 地址。开发命令默认监听 `0.0.0.0`，手机与电脑连接同一个局域网后，可以通过 `http://本机IP:3000` 访问。

## 3. 构建与启动生产版本

```bash
npm run build
npm run start
```

本项目不包含后端数据库，部署时需要选择支持 Node.js 或 Cloudflare Worker 兼容输出的平台。

## 4. 难度配置

所有难度数值集中在 `game/config.ts` 的 `DIFFICULTIES` 中。

| 字段 | 作用 |
| --- | --- |
| `targetWild` | 场上野生生物目标数量 |
| `speedMultiplier` | 野生生物移动速度倍率 |
| `lowerWeight` | 生成低于玩家等级生物的权重 |
| `equalWeight` | 生成与玩家同级生物的权重 |
| `higherWeight` | 生成高于玩家等级危险生物的权重 |
| `spawnDelay` | 生物不足时的补充间隔，单位毫秒 |

三个生成权重之和应保持为 `1`。

## 5. 生物等级配置

`game/config.ts` 的 `CREATURES` 数组按照进化顺序定义生物。

| 数组下标 | 生物 |
| ---: | --- |
| 0 | 小蝌蚪 |
| 1 | 小青蛙 |
| 2 | 小海龟 |
| 3 | 小金鱼 |
| 4 | 锦鲤 |
| 5 | 电鳗 |
| 6 | 鲨鱼 |
| 7 | 鲸鱼 |
| 8 | 蛟龙 |
| 9 | 神龙 |

`color` 和 `accent` 控制程序绘制角色的主色与装饰色，`radius` 影响基础尺寸，`aspectRatio` 和 `visualScale` 控制高阶生物的长宽与放大比例。碰撞范围会同步计入横向体型，避免出现画面已接触但未触发吞噬的情况。

## 6. 移动与碰撞

- 玩家自动前进速度在 `SummonDragonScene.updatePlayer` 中设置。触摸按下点作为隐形摇杆中心，拖动向量通过 `updateHeadingFromJoystick` 立即改变方向。
- 队伍成员使用紧凑三列叠放编队，主角保持完整尺寸，其他成员缩小显示。
- 野生生物速度范围在 `updateWild` 和 `spawnWild` 中设置，再乘以难度倍率。
- 玩家没有受击无敌时间；接触高级生物会立即减员，持续接触可连续触发。
- 玩家与野生生物、野生生物彼此都使用圆形距离判定。

## 7. 教程本地记录

教程状态保存在：

```text
summon-dragon-tutorial-seen
```

需要重新测试首次教程时，可在浏览器开发者工具中删除该本地存储项。

## 8. 素材

- `public/assets/pond-background.png`：ImageGen 生成的原创竖屏池塘底图。
- `public/og.png`：分享预览图。
- `public/assets/music/backgroundmusic.mp3`：循环背景音乐，首页加载后立即尝试播放；若浏览器拦截自动播放，会在玩家首次触摸或按键时自动补播。
- `public/assets/music/eat.mp3`：吞噬音效。
- `public/assets/music/eated-sound.mp3`：队伍成员被高级生物吞噬的音效。
- `public/assets/music/failed.mp3`：游戏失败音效。
- `public/assets/music/winner.mp3`：胜利音效。
- 生物角色通过 Phaser Graphics 在启动时生成纹理，确保轮廓、尺寸和颜色可直接配置。

## 9. 移动端适配

- 屏幕内部逻辑尺寸为 `390 × 844`，池塘地图尺寸为 `780 × 1350`。
- Canvas 根据可用屏幕等比例缩放，镜头只显示地图的一部分并持续跟随主角。初始缩放为 `1.58`，随等级提升逐步降低到最小 `1.25`，因此视野逐渐扩大但仍保持较近。首页使用 `public/assets/dragon.png` 作为中右侧漂浮神龙，原池塘背景保持不变。
- 手机端占满可视区域，电脑端保持竖屏画布居中。
- 横屏时暂停并显示旋转提示。
- 页面进入后台时自动暂停。
- 游戏区域设置 `touch-action: none`，不会触发页面滚动。

## 10. 上线前建议检查

1. 在实际 iPhone Safari、Android Chrome 和微信内置浏览器各试玩至少一局。
2. 检查简单模式是否能在 3～5 分钟内通关。
3. 检查刘海屏顶部暂停按钮是否可点击。
4. 检查横竖屏切换、后台恢复和重新开始。
5. 根据试玩结果只调整 `game/config.ts`，避免在首版扩大功能范围。
